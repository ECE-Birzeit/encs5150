# Experiments

Each guide is a step-by-step replacement for the matching chapter of the [department manual](/ENCS515-Manual.pdf){target="_blank"}, updated for current Android Studio. Linked experiments are ready, and the rest are coming soon. Finish the [Setup Guide](/setup) before your first lab.

| No. | Experiment | Topics |
| :-: | --- | --- |
| 1 | [Introduction to Android Programming](./exp1-intro) | Android Studio, project structure, Activities, the manifest, running on an emulator and a device |
| 2 | [Android Layouts](./exp2-layouts) | Views and ViewGroups, XML layouts, layouts built in code, Intents between Activities, event listeners |
| 3 | Using Intents and Notifications | Implicit Intents (Maps, email, dialer), Toasts, status-bar notifications |
| 4 | SQLite Database | Creating and querying a local database, custom Views, confirmation dialogs |
| 5 | Frame Animation and Tween Animation | Frame-by-frame animation, translate / rotate / scale, the `Animation` class |
| 6 | Singleton and Shared Preferences | The singleton pattern, saving key–value data with `SharedPreferences` |
| 7 | Fragments | Fragment lifecycle, multi-pane UIs, swapping Fragments at runtime |
| 8 | Integrating REST API into Android Application | HTTP GET and POST requests, parsing JSON into Java objects |
| 9 | Spring Boot Part 1 | Spring Boot fundamentals, building REST services with Spring MVC |
| 10 | Spring Boot Part 2 | Continues Part 1 |

::: info
Lab tasks ("Todo") are handed out by your TA during the lab session and are not published here.
:::
